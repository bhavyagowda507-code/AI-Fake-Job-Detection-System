\# AI-Powered Fake Job Posting Detection and Trust Analysis System



A full-stack machine learning web ecosystem built to analyze, process, and classify potential employment scams using natural language processing (NLP) and optical character recognition (OCR).



\## 🚀 System Features

\* \*\*Job Verifier Portal:\*\* Real-time text classification engine powered by Scikit-Learn vector arrays.

\* \*\*ScamSnap Vision Engine:\*\* Built-in PDF reader (`pypdf`) and screenshot analyzer (`easyocr`) to scan document structures natively.

\* \*\*Unified UI:\*\* Responsive, integrated dashboard layout with live navigation arrays.
